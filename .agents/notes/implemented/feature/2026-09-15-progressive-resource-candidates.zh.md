# Agent Note: 渐进资源候选

Status: implemented

[English](2026-09-15-progressive-resource-candidates.md) | 中文

## Problem

共享资源来源汇总本地文件、Session 和远程 Studio 列表。等待所有列表完成，会让较慢的后端拖住已可用的资源。替换已经部分显示的数组，还可能让键盘选中项变成同一索引处的另一资源。

## Decision

[原生输入触发菜单](../../../../packages/client/ui-input-trigger/README.zh.md) 接受请求范围内、最终结束前的候选发布。来源继续负责后端发现、分组和错误呈现；控制器负责取消发布和原生选择。禁用状态行不能成为选中项。同一查询内的更新按候选的不透明 value 保留选中项；没有 value 的候选按名称和分组匹配。最终结束会关闭发布回调；更换查询、关闭菜单和销毁 Session 会使尚未完成的发布失效。

## Alternatives considered

等待所有提供者保留了单一最终结果，但会延迟独立选项。把每个发现的后端注册为全局触发来源，会把 Session 范围的发现与全局来源名录、单一来源启动器耦合。另设资源弹窗会重复原生输入框的交互规则。

## Consequences

Kit 保留单一原生资源来源和编解码器，同时在各提供者返回时显示结果。它负责本地化的加载和失败行。菜单的空结果自动关闭规则也适用于中间发布。控制器、归约器和菜单渲染测试覆盖部分结果可选、稳定选择、禁用状态行以及丢弃迟到发布。候选发现不改变模型输入或 Session 日志格式。
